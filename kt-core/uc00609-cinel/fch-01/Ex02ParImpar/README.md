# Ex02ParImpar

## Objetivo

Desenvolver uma aplicação Android simples capaz de verificar se um número inteiro é par ou ímpar.

## Tecnologias Utilizadas

- Android Studio Panda 1 (2025.3.1)
- Kotlin
- Android SDK
- XML (Layout)

## Funcionalidades

A aplicação permite:

1. Introduzir um número inteiro.
2. Clicar no botão **Verificar**.
3. Determinar se o número é par ou ímpar.
4. Apresentar o resultado no ecrã.

## Exemplos

### Exemplo 1

Entrada:

8

Saída:

O número 8 é PAR

### Exemplo 2

Entrada:

7

Saída:

O número 7 é ÍMPAR

## Estrutura da Interface

- EditText → introdução do número.
- Button → execução da verificação.
- TextView → apresentação do resultado.
