# UC00609 - Desenvolvimento de Aplicações Android com Kotlin

Repositório de exercícios desenvolvidos durante a unidade curricular UC00609 do curso CET TPSI do CINEL Porto.

## Objetivo

Este repositório contém exercícios práticos desenvolvidos em Android Studio utilizando Kotlin, com foco na aprendizagem dos conceitos fundamentais de:

- Interfaces gráficas Android
- Eventos e interação com o utilizador
- Manipulação de componentes visuais
- Estruturas de decisão
- Estruturas de repetição
- Coleções (Listas)
- Programação orientada a eventos

---

# Exercício 1 - Olá Utilizador

## Descrição

Aplicação que solicita o primeiro nome e o último nome do utilizador e apresenta uma saudação personalizada.

## Funcionalidades

- Introdução do primeiro nome
- Introdução do último nome
- Botão "Saudar"
- Mensagem de saudação
- Validação de nome vazio
- Mensagens Toast

## Personalização Visual

Mascote: Capivara Pescadora

### Estado Inicial

A capivara encontra-se a pescar num riacho.

### Após Saudação

A capivara captura um peixe e celebra o sucesso.

## Conceitos Utilizados

- EditText
- Button
- TextView
- ImageView
- Toast
- Eventos de clique
- Validação de dados

# Exercício 2 - Dados Pessoais

## Descrição

Aplicação que permite registar e apresentar informações pessoais do utilizador.

## Funcionalidades

- Introdução do nome
- Introdução da idade
- Introdução da altura
- Botão "Registar"
- Apresentação formatada dos dados

## Personalização Visual

Tema: Escritório de Recursos Humanos

Mascote: Capivara Recrutadora

### Estado Inicial

A capivara encontra-se a recolher informações numa prancheta.

### Após Registo

A capivara apresenta a ficha do candidato preenchida com sucesso.

## Conceitos Utilizados

- EditText
- Button
- TextView
- ImageView
- Manipulação de Strings
- Eventos de clique

# Exercício 3 - Maioridade

## Descrição

Aplicação que verifica se uma pessoa é maior de idade (18 anos ou mais).

## Funcionalidades

- Introdução do nome
- Introdução da idade
- Verificação da maioridade
- Mensagens de autorização ou negação de acesso

## Personalização Visual

Tema: Clube Noturno

Mascote: Capivara Segurança

### Estado Inicial

A capivara segurança controla a entrada do clube.

### Utilizador Maior de Idade

A capivara autoriza a entrada e dá acesso ao recinto.

### Utilizador Menor de Idade

A capivara impede a entrada e nega o acesso.

## Conceitos Utilizados

- EditText
- Button
- TextView
- ImageView
- Estruturas condicionais (if / else)
- Conversão de dados
- Eventos de clique

# Exercício 4 - Números Pares

## Descrição

Aplicação que apresenta os números pares entre 1 e 20.

## Funcionalidades

- Execução da missão através de botão
- Geração automática dos números pares
- Apresentação dos resultados no ecrã
- Aprovação visual da missão concluída

## Personalização Visual

Tema: Nave Espacial

Mascote: Capivara Astronauta

### Estado Inicial

A capivara encontra-se numa missão espacial.

### Após Executar a Missão

São apresentados os números pares entre 1 e 20 e surge um carimbo de aprovação da missão.

## Conceitos Utilizados

- Button
- TextView
- ImageView
- Estruturas de repetição (for)
- Operador módulo (%)
- Eventos de clique

# Exercício 5 - Lista de Nomes

## Descrição

Aplicação que permite adicionar nomes a uma lista apresentada no ecrã.

## Funcionalidades

- Introdução de nomes
- Adição à lista
- Apresentação dinâmica dos nomes
- Atualização automática da interface

## Personalização Visual

Tema: Arquibancada de Futebol

Mascotes: Capivaras Adeptas

### 1º Nome

Surge uma capivara adepta da Seleção Brasileira.

### 2º Nome

Surge uma segunda capivara adepta da Seleção Portuguesa.

### 3º Nome ou Mais

Surge um grupo de três capivaras adeptas das seleções:

- Brasil
- Portugal
- Angola

celebrando juntas numa arquibancada festiva.

## Conceitos Utilizados

- MutableList
- Atualização dinâmica da interface
- Estruturas condicionais
- Manipulação de ImageView
- Eventos de clique

# Notas Pessoais

Como forma de aumentar a motivação e tornar a aprendizagem mais divertida, os exercícios foram personalizados com uma mascote recorrente (Capivara), mantendo a funcionalidade original exigida pelos enunciados.

Cada exercício representa uma profissão ou situação diferente vivida pela mascote:

- Capivara Pescadora
- Capivara Recrutadora
- Capivara Segurança
- Capivara Astronauta
- Capivaras Adeptas

O objetivo não é alterar os requisitos dos exercícios, mas criar uma identidade visual própria durante o processo de aprendizagem.
