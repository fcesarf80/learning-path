# Gestor de Biblioteca

Projeto desenvolvido em Python com Tkinter para a disciplina UC00608.

## Objetivo

Desenvolver um sistema de gestão de biblioteca contendo:

- Gestão de Livros
- Gestão de Utilizadores
- Empréstimos
- Devoluções
- Histórico
- Estatísticas

## Tecnologias

- Python
- Tkinter
- CSV
- Programação Orientada a Objetos

## Estado Atual

- Estrutura inicial criada
- Planeamento das telas em andamento
