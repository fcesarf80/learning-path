# Gestão de Elenco e Booking Artístico

Aplicação desktop desenvolvida em C# Windows Forms com MySQL para gestão de artistas e eventos.

## Funcionalidades

- Inserção de artistas
- Edição de artistas
- Eliminação de artistas
- Pesquisa por nome
- Gestão de bookings
- Gestão de fotografias
- Integração com MySQL

## Tecnologias

- C#
- Windows Forms
- MySQL
- MySql.Data

## Estrutura da Base de Dados

- categoria
- artista
- booking

## Como Executar

1. Criar a base de dados MySQL.
2. Executar o script booking_artistico.sql.
3. Abrir a solução no Visual Studio.
4. Restaurar as dependências.
5. Executar a aplicação.
