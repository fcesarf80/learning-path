# Documentação Técnica

## Projeto: ex-06-gestao-turne-musical

---

# Objetivo

Desenvolver uma aplicação Java Swing para gestão de uma turnê musical fictícia.

A aplicação permitirá:

- adicionar concertos
- editar concertos
- remover concertos
- pesquisar eventos
- guardar dados em ficheiros
- organizar informações da turnê

---

# Tecnologias Utilizadas

- Java
- Java Swing
- NetBeans
- JTable
- JFileChooser
- Manipulação de ficheiros

---
